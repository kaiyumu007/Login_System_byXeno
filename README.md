# 🔐 Simple Signup & Login System

A simple Signup & Login System made with Python.  
Perfect for Python beginners who want to learn Dictionary, Function and Loop in a real project.

## ✨ Features
- Create a new account (Signup)
- Login with username & password
- Stores users using Python Dictionary
- Wrong password shows error message
- Clean menu system with While Loop

## 🛠️ Technologies Used
- Python 3
- Dictionary
- Function (`def`)
- While Loop
- If / Elif / Else
